# RoboCraft

**RoboCraft** — учебный проект по дисциплине «Прикладная электроника» в НИТУ МИСИС.

Цель проекта — разработать и испытать мобильного робота для соревнования на скорость. По условиям задания робот должен передвигаться **без колёс и гусениц**.

## Задача и ограничения

- Создать работоспособный механизм передвижения без колёс и гусениц.
- Использовать электродвигатель постоянного тока, автономный источник питания и выключатель.
- Подобрать конструкцию и передачу движения для эффективного преодоления дистанции.
- Провести испытания и при необходимости доработать конструкцию.

## Принцип работы

Электродвигатель создаёт вращательное движение, которое через механическую передачу приводит в действие движущий механизм. При разработке учитываются устойчивость, масса и скорость передвижения.

> Характеристики двигателя, передаточное отношение, размеры и скорость можно добавить после измерений.

## Испытания

| Параметр | Что проверяем |
| --- | --- |
| Скорость | Время прохождения заданной дистанции |
| Устойчивость | Сохранение направления и отсутствие опрокидывания |
| Надёжность | Работу механизма при повторных запусках |
| Эффективность движения | Потери движения и проскальзывание опор |

Результаты измерений будут добавлены после испытаний.
