# RoboCraft

**RoboCraft** — учебный проект по дисциплине «Прикладная электроника» в НИТУ МИСИС.

Цель проекта — разработать и испытать мобильного робота для соревнования на скорость. По условиям задания робот должен передвигаться **без колёс и гусениц**.

## Задача и ограничения

- Создать работоспособный механизм передвижения без колёс и гусениц.
- Использовать электродвигатель постоянного тока, автономный источник питания и выключатель.
- Подобрать конструкцию и передачу движения для эффективного преодоления дистанции.
- Провести испытания и при необходимости доработать конструкцию.

## Принцип работы

Электродвигатель создаёт вращательное движение, которое через механическую передачу приводит в действие движущий механизм. При разработке учитываются устойчивость, масса и скорость передвижения.

> Характеристики двигателя, передаточное отношение, размеры и скорость можно добавить после измерений.

## Разработка и конструкция робота

### Концепция

В качестве основы конструкции была выбрана схема робота-гребца, вдохновлённая роботами семейства **RHex**. В отличие от классического RHex с шестью вращающимися ногами, наш робот использует только две приводные опоры — по одной с каждой стороны корпуса.

Передвижение осуществляется за счёт вращения гибких ножек, которые периодически взаимодействуют с поверхностью и создают тяговое усилие. При этом нижняя часть корпуса скользит по поверхности трассы.

Основной задачей при разработке стало достижение высокой скорости движения при минимальной массе, достаточной жёсткости конструкции и хорошем сцеплении опор с поверхностью.

### Эволюция конструкции

#### 1. Первоначальный вариант — гибкие ножки

На первом этапе были изготовлены две ножки из пластиковых кабельных стяжек — по одной с каждой стороны робота.

Этот материал был выбран благодаря небольшой массе, гибкости, простоте обработки и доступности.

Однако испытания показали, что одиночные стяжки обладают недостаточной жёсткостью. Под нагрузкой они чрезмерно деформировались, что снижало эффективность передачи усилия от двигателя к поверхности.

#### 2. Увеличение жёсткости

Для решения проблемы конструкция была усилена: вместо одной стяжки с каждой стороны стали использоваться две параллельные.

Это позволило повысить жёсткость опор и уменьшить их деформацию при контакте с поверхностью.

Таким образом, итоговая конструкция получила четыре гибких элемента, объединённых попарно в две рабочие ножки.

#### 3. Улучшение сцепления с поверхностью

Следующей проблемой оказалось недостаточное сцепление пластиковых ножек с трассой.

Из-за проскальзывания часть движения опор не преобразовывалась в поступательное движение робота.

Для увеличения сцепления на контактные участки ножек были добавлены силиконовые накладки, выполняющие функцию своеобразных «покрышек».

Перед каждым забегом силиконовые поверхности протирались спиртом для удаления загрязнений и восстановления стабильного контакта с поверхностью трассы.

### Корпус и материалы

Конструкция корпуса была разработана с учётом требований к небольшой массе, достаточной жёсткости и простоте изготовления.

| Элемент | Материал | Назначение |
|---|---|---|
| Корпус | Листовой ПВХ-пластик | Основа конструкции и крепление компонентов |
| Нижняя подложка | Вспененный ПВХ | Лёгкая опорная часть корпуса |
| Приводные ножки | Пластиковые кабельные стяжки | Создание тягового усилия |
| Контактные накладки | Силикон | Увеличение сцепления с трассой |
| Скользящие подкладки | Ткань | Снижение сопротивления скольжению корпуса |

Особенностью конструкции стало разделение функций между приводными ножками и нижней частью корпуса.

Ножки обеспечивают сцепление с трассой и создают тяговое усилие, тогда как тканевые подкладки на нижней поверхности корпуса уменьшают сопротивление скольжению.

Таким образом, при разработке решались две противоположные задачи: **увеличение трения в зоне контакта приводных ножек и уменьшение трения под корпусом робота**.

### Итоговая конструкция

В результате последовательных доработок была получена конструкция двухопорного робота-гребца с усиленными пластиковыми ножками, силиконовыми контактными накладками и скользящим корпусом.

Основные изменения в процессе разработки были направлены на устранение трёх проблем:

1. **Недостаточная жёсткость ножек** — решена использованием парных пластиковых стяжек.
2. **Проскальзывание приводных опор** — уменьшено добавлением силиконовых накладок.
3. **Сопротивление движению корпуса** — уменьшено использованием тканевых скользящих подкладок.

Проект демонстрирует, как изменение жёсткости элементов конструкции, коэффициента трения контактных поверхностей и распределения функций между опорами влияет на характер движения мобильного робота.
